REGEX PATTERN FOR EXTRACTION (Python):
```python
import re

def extract_readable_name(concatenated_name):
    name = concatenated_name
    name = re.sub(r'BroadBasedIndexMember$', '', name)
    name = re.sub(r'Member$', '', name)
    name = re.sub(r'\d{4,5}$', '', name)
    # Remove manager prefixes (list provided in docs)
    # Normalize camelCase to readable format
    return name
```

DATABASE SCHEMA (SQL):
```sql
CREATE TABLE benchmark_name_mapping (
    id INTEGER PRIMARY KEY,
    concatenated_name VARCHAR(500) UNIQUE NOT NULL,
    readable_name VARCHAR(500),
    index_provider VARCHAR(100),
    isin_or_ticker VARCHAR(20),
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

QUERY TO FIND UNMAPPED BENCHMARKS:
```sql
SELECT COUNT(*) FROM performance p
LEFT JOIN benchmark_name_mapping m ON p.benchmark_name = m.concatenated_name
WHERE m.id IS NULL AND p.benchmark_name IS NOT NULL;
```
